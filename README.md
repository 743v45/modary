# Modary — 模型 Corpus 截止时间记录

通过二分法提问 2025 之后的事件，定位各 AI 模型的训练数据截止时间。

## 探测方法

- 只凭模型训练数据回答，**禁止使用任何工具**
- 二分法逐步缩小范围，找到「知道」与「不知道」的边界

## 目录结构

```
modary/
├── raw/                          # 原始对话记录
│   └── {模型原名}-{YYYY-MM-DD}.md
├── CORPUS.md                     # 汇总表
└── CLAUDE.md                     # 项目流程规范
```

## 流程

1. 用二分法向模型提问，判定 Corpus 截止时间
2. 将原始对话存入 `raw/{模型原名}-{日期}.md`
3. 在 `CORPUS.md` 追加一行记录
